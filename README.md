# 🛒 BuyT — Full-Stack E-Commerce Web Application

BuyT is a full-stack e-commerce web application built with Django and
PostgreSQL. It provides users with a complete online shopping experience,
including product discovery, cart management, wishlist, checkout, and
order management.

## 🚀 Live Demo

https://buyt-ta3n.onrender.com

## ✨ Features

### 👤 User Features
- User registration and login
- Email OTP verification
- Secure password hashing
- Session-based authentication
- User profile
- Product search
- Category and brand filtering
- Product details
- Shopping cart
- Wishlist
- Checkout
- Order management

### 🤖 AI Shopping Assistant
- AI-powered shopping chatbot
- Product-related queries
- Shopping assistance
- Product recommendations
- LLM API integration

### 🔐 Admin Features
- Admin authentication
- Admin dashboard
- Product management
- Category management
- Brand management
- User management
- Inventory management
- Order management
- Payment/order status management
